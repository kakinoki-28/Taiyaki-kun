## 環境

Unity バージョン: 6000.3.21f1

## ディレクトリ構成
```
.
├── Assets/
│   ├── アセットストア由来のファイル群（導入する場合）
│   └── Project/
│       ├── Scenes/
│       │   ├── 本番用シーン
│       │   └── Test/
│       │       ├── Developer1/
│       │       │   └── Developer1の作業用シーン
│       │       ├── Developer2/
│       │       │   └── Developer2の作業用シーン
│       │       └── ...
│       ├── Prefabs/
│       │   └── プレハブ化するオブジェクト
│       ├── Scripts/
│       │   └── C#などのスクリプト
│       ├── Models/
│       │   ├── chara 01/
│       │   │   └── キャラ１のモデルや関連するアニメーターコントローラー、モーション等
│       │   ├── chara 02/
│       │   │   └── キャラ２のモデルや関連するアニメーターコントローラー、モーション等
│       │   └── ...
│       ├── Materials/
│       │   └── マテリアルや関連するシェーダー等
│       ├── PhysicsMaterials/
│       │   └── 物理エンジンで使用するマテリアル
│       ├── Fonts/
│       │   └── フォント
│       ├── Textures/
│       │   └── テクスチャー
│       ├── Audio/
│       │   └── 音声ファイル
│       └── Settings/
│           └── 各種設定
└── Packages/
    │   └── パッケージの管理
    └── ...
```
